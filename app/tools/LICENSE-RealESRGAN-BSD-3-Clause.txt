The tools\realesrgan-ncnn-vulkan folder in the portable package contains an
unmodified copy of the official Real-ESRGAN Windows release
(realesrgan-ncnn-vulkan-20220424-windows.zip, v0.2.5.0):

    realesrgan-ncnn-vulkan.exe      https://github.com/xinntao/Real-ESRGAN
    vcomp140.dll                    MSVC OpenMP runtime, redistributable
    models/realesrgan-x4plus.*      Real-ESRGAN x4plus weights
    models/realesrgan-x4plus-anime.*  Real-ESRGAN x4plus-anime weights

Only the two models this application uses are kept; the anime-video models,
sample images and demo video from the original archive are not included.

That executable is built on ncnn and realsr-ncnn-vulkan, and the whole release
is distributed under the BSD 3-Clause licence reproduced below.
